# Intents

Each `NN-name.zsh` file is one thing install.sh can set up. They're asked
and applied in file-name order, so an intent comes after the ones it
needs. A file sets these variables:

| Variable | Meaning |
|---|---|
| `id` | Short name, used in `requires`, `works_best_with` and the answers file (`intent_<id>`) |
| `title`, `why` | Shown in the question, and in the README |
| `always=1` | Not asked; always part of the setup (Foundation) |
| `requires` | Intents that must be chosen too; otherwise this one is skipped with a reason |
| `works_best_with` | Soft dependencies: a note when they aren't chosen |
| `packages` | `"<source> <what>"` lines. `brew` and `cask` lines are installed by `install_packages`; the rest document what `apply` does. Sources: `apple official brew cask git npm nodejs rustup lazy treesitter coc repo` |
| `hosts` | Download hosts beyond Homebrew's, for the reachability check and the README |
| `sudo_steps` | What it uses sudo for (README only) |
| `targets` | Paths it links, for the pre-check and `--unlink` |
| `cask_apps` | `cask app-bundle` pairs, so an app installed some other way counts as present |

and may define these functions:

| Function | When it runs |
|---|---|
| `available` | Before asking. Return 1 and set `WHY_NOT` to skip the intent |
| `ask` | After the intent is chosen, for follow-up questions (store answers in `ANS`) |
| `apply` | Once to build the plan, once to apply it. Make every change through the helpers in `lib/actions.zsh` (`install_packages`, `link`, `copy_file`, `task`, ...), which record, run or print depending on `MODE` |
| `finish` | After every chosen intent has been applied |

`inventory.txt` is generated by `install.sh --docs --refresh` and feeds the
README's "pulled in" lists. Run `install.sh --docs` after changing an intent.
